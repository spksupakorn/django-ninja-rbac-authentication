Lesson 14 · 15 minutes

Password hash ไม่ใช่ password ที่เข้ารหัส

ระบบที่ปลอดภัยไม่เก็บ password จริง และไม่ต้องถอดกลับออกมาได้. มันเก็บ hash ซึ่งใช้ตรวจว่า password ที่ส่งเข้ามาตรงกับของเดิมหรือไม่เท่านั้น

Hashing vs encryption

Encryption: เข้ารหัสและถอดกลับได้เมื่อมีกุญแจ เหมาะกับข้อมูลที่ต้องอ่านกลับ

Password hashing: one-way; เป้าหมายคือเปรียบเทียบ ไม่ใช่คืน password เดิม

register:
raw password → Argon2id hash → database

login:
raw password + stored hash → verify → True / False

แม้ database รั่ว attacker ไม่ควรได้ raw password ทันที; hash algorithm ที่ออกแบบมาดีจะทำให้การเดารหัสผ่านแต่ละครั้งมีต้นทุนสูง

Argon2id ในโปรเจกต์นี้

PASSWORD_HASHERS = [
    "django.contrib.auth.hashers.Argon2PasswordHasher",
    "django.contrib.auth.hashers.PBKDF2PasswordHasher",
    ...
]

Django ใช้ hasher ตัวแรกสำหรับ password ใหม่ จึงเลือก Argon2id เป็นอันดับแรก. Hasher อื่นเก็บไว้เพื่อ verify password เก่าที่อาจถูกสร้างด้วย algorithm ก่อนหน้าได้

อย่า hash เองด้วย string manipulation

# ถูก: Django จัดการ salt และ format hash ให้
user.set_password(raw_password)
user.check_password(raw_password)

# ผิด: เก็บ raw password
user.password = raw_password

M4 จะมี wrapper hash_password / verify_password เพื่อให้ service ไม่ต้องเรียก primitive โดยตรง แต่หลักการเหมือน set_password และ check_password

ทำไม async code ยังต้องระวัง?

Argon2id ตั้งใจให้ใช้ CPU และ memory มากกว่าการเปรียบเทียบ string ธรรมดา. หากเรียกมันบน event loop โดยตรง request อื่นอาจรอช้า

from asgiref.sync import sync_to_async

verify_password_async = sync_to_async(
    verify_password,
    thread_sensitive=False,
)

is_valid = await verify_password_async(raw_password, stored_hash)

การห่อด้วย sync_to_async(..., thread_sensitive=False) ย้ายงาน CPU-bound ไป thread ที่เหมาะสม แทนที่จะ block event loop ของ ASGI server

Timing attack และ dummy verify

ถ้า email ไม่พบแล้ว return ทันที แต่กรณี password ผิดต้อง hash verify attacker อาจวัดเวลาตอบและเดาได้ว่า account มีอยู่หรือไม่. ดังนั้น login flow จะทำ dummy password verify แม้หา user ไม่พบ เพื่อให้เวลาสองกรณีใกล้กัน
