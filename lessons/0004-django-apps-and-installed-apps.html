โฟลเดอร์ไหน “เป็น” Django app?

Python package กลายเป็น Django app ที่ทำงานจริงเมื่อถูกประกาศใน INSTALLED_APPS. Django ใช้รายชื่อนี้สร้างทะเบียนกลางของ domain ทั้งหมดในโปรเจกต์

เริ่มจาก settings

# config/settings/base.py
INSTALLED_APPS = [
    "django.contrib.admin",
    "django.contrib.auth",
    # ... Django built-in apps
    "apps.accounts",
    "apps.authz",
    "apps.common",
]

รายการนี้ ไม่ใช่ URL routes. มันบอก Django ว่า package ใดเป็นส่วนหนึ่งของ application system: Django จะค้นหา models, migrations, admin configuration และ resources ที่เกี่ยวข้องใน app เหล่านั้นเมื่อ boot

Python package vs Django app

Python package: โฟลเดอร์มี __init__.py; Python import ได้

Django app: Python package ที่ Django register ผ่าน INSTALLED_APPS; จึงมี lifecycle และสามารถมี models/migrations ได้

ดังนั้น apps/accounts/ เป็น package อยู่แล้ว แต่การใส่ "apps.accounts" ลงใน settings ทำให้มันมีบทบาทใน Django project

apps.py บอกตัวตนของ app

# apps/accounts/apps.py
class AccountsConfig(AppConfig):
    default_auto_field = "django.db.models.BigAutoField"
    name = "apps.accounts"
    label = "accounts"
  • name คือ Python import path ของ app
  • label คือชื่อสั้นที่ Django ใช้ระบุตัว app เช่น prefix ใน migration
  • default_auto_field กำหนดชนิด primary key ที่ model ใหม่จะใช้เป็นค่าเริ่มต้น

ใน Django รุ่นปัจจุบัน เมื่อ package มี apps.py ที่มี AppConfig เดียว Django เลือก config นี้ให้อัตโนมัติเมื่อเราใส่ "apps.accounts" ใน INSTALLED_APPS

สาม domain ของเรา

accounts — identity: User, email, password (เริ่ม M1)
authz — authorization: Role, Permission, JWT (เริ่ม M2 เป็นต้นไป)
common — ส่วนที่ใช้ข้าม domain: exceptions, pagination, throttling

ตอน M0 โฟลเดอร์เหล่านี้เป็น skeleton โดยตั้งใจ: เราลงทะเบียน domain ก่อน เพื่อให้ M1 สร้าง custom User และ migration แรกใน app ที่ถูกต้อง

Quiz: อะไรทำให้ Django รู้จัก apps.accounts เป็น app ของโปรเจกต์?

A = urlpatterns · B = INSTALLED_APPS · C = ASGI_APPLICATION

ลองทำเอง

เปิด config/settings/base.py แล้วหา app ของเรา 3 ชื่อ. ต่อด้วยเปิด apps/accounts/apps.py. ลองตอบ: ถ้าเอา "apps.accounts" ออกจาก INSTALLED_APPS แล้ว M1 สร้าง User model อยู่ในโฟลเดอร์เดิม Django จะสร้าง migration ให้หรือไม่? เพราะอะไร?
