AuthService คือผู้ประสาน auth flow

Router รับ HTTP; repository ทำ database I/O; แต่ use case ที่ต้องตัดสินใจและเรียงหลายขั้นตอนอยู่ใน AuthService. นี่คือที่ที่ register, login, refresh และ logout มีความหมายทางธุรกิจครบถ้วน

1. Register

register(email, password)
  → ตรวจว่า email ยังไม่ซ้ำ
  → UserManager.create_user()  # hash password
  → หา default role: "user"
  → สร้าง UserRole(user, role)
  → คืนผลลัพธ์ที่ปลอดภัย

Register ไม่ควรให้ client เลือก admin เอง. Policy บอกว่า user ใหม่ได้ DEFAULT_USER_ROLE = "user"; นี่คือการเชื่อม custom User จาก M1 เข้ากับ RBAC จาก M2

2. Login

login(email, password)
  → repository หา user จาก email
  → verify password (หรือ dummy verify หากไม่พบ user)
  → resolve roles/perms
  → ออก access token
  → สร้าง refresh family + hash ของ raw refresh token ใน DB
  → คืน access + raw refresh token

ถ้าหา user ไม่พบหรือ password ไม่ถูก service raise InvalidCredentials เดียวกัน. Access token มี snapshot ของ roles/perms; refresh record มี state สำหรับ rotation ใน database

3. Refresh

refresh(raw_refresh)
  → hash raw token แล้วหา RefreshToken record
  → ตรวจ expiry และ revoked_at
  → ถ้า revoked: revoke ทั้ง family, raise TokenReused
  → ถ้ายัง valid: revoke token เดิม
  → ออก access ใหม่ + refresh ใหม่ใน family เดิม
  → คืน token pair ใหม่

นี่คือจุดที่ rotation และ reuse detection จาก Lesson 16 กลายเป็น code path จริง

4. Logout

logout(raw_refresh)
  → hash raw token แล้วหา record
  → ตั้ง revoked_at
  → return success

Logout revoke refresh token เพื่อไม่ให้ขอ access tokens ใหม่ได้. Access token ที่ออกไปแล้วจะหมดอายุตาม TTL สั้นของมัน

Service เรียกอะไรบ้าง?

AccountsRepository: หา user
AuthzRepository: หา default role, assign role, resolve perms
Password wrapper: hash/verify แบบไม่ block event loop
JWT module: encode/decode access token
RefreshToken repository: persist/revoke/rotate tokens

Service ไม่ควรเรียก request, ไม่ควรสร้าง HTTP response, และไม่ควรเขียน ORM query ตรง ๆ

ตัวอย่างที่ผิดขอบเขต

# API router ไม่ควรทำทั้งหมดนี้เอง
user = await User.objects.aget(email=input.email)
if not user.check_password(input.password):
    return 401
# ... สร้าง JWT และ RefreshToken ต่อ

โค้ดแบบนี้ผสม HTTP, ORM, password และ token policy ในจุดเดียว จึง test และเปลี่ยนยาก. Router ที่ดีควรมีหน้าที่สั้น: validate input → await service → serialize result
