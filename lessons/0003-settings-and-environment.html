ค่าจาก `.env` เข้า Django อย่างไร?

โปรเจกต์นี้ไม่เขียน password, database URL หรือ JWT secret ลงใน source code. เราใส่ค่าไว้ใน environment แล้วให้ Pydantic ตรวจมันก่อนส่งต่อให้ Django

สี่ชิ้นที่ทำงานร่วมกัน

.env: เก็บค่าบนเครื่อง เช่น DATABASE_URL
Settings(BaseSettings): อ่านและตรวจ type/รูปแบบ
base.py: สร้าง Django settings กลาง
dev.py หรือ prod.py: ปรับให้เหมาะกับ environment

1. Django เลือก settings module

# config/asgi.py และ manage.py
os.environ.setdefault("DJANGO_SETTINGS_MODULE", "config.settings.dev")

ชื่อนี้บอก Django ให้ import config/settings/dev.py เมื่อเริ่มต้น. คำว่า setdefault หมายถึง: ใช้ dev เฉพาะเมื่อผู้รันยังไม่ได้กำหนดค่าอื่นไว้

# config/settings/dev.py
from .base import *

DEBUG = True

ดังนั้น dev ได้ค่ากลางทั้งหมดจาก base.py แล้ว override เฉพาะค่าที่ต่าง เช่น DEBUG. Production ก็ใช้ฐานเดียวกัน แต่เปิด security settings ที่เข้มกว่า

2. `.env` ไม่ใช่ Python code

# .env (อยู่ใน .gitignore)
DATABASE_URL=postgresql://postgres:postgres@localhost:5432/rbac_auth
JWT_SECRET=replace-with-a-long-random-secret
ACCESS_TTL=15m

นี่เป็นเพียง NAME=value. เพราะแต่ละเครื่องมี database และ secret ต่างกัน จึง commit เฉพาะ .env.example เป็น template แต่ไม่ commit .env ที่ใช้จริง

3. Pydantic รับและตรวจค่า

# config/settings/base.py
class Settings(BaseSettings):
    model_config = SettingsConfigDict(env_file=BASE_DIR / ".env")

    database_url: str = Field(validation_alias="DATABASE_URL")
    jwt_secret: SecretStr = Field(validation_alias="JWT_SECRET", min_length=32)

settings = Settings()

เมื่อสร้าง Settings(), Pydantic อ่าน environment และไฟล์ .env, map ชื่อ uppercase ไปยัง field แบบ typed, แล้ว validate. เช่น database URL ต้องเป็น PostgreSQL URL และ JWT secret ต้องยาวพอ

ผลลัพธ์สำคัญ: ถ้าค่าใดหายหรือผิด app จะ fail ระหว่าง boot. ดีกว่ารอให้ error เกิดขึ้นหลังมี request เข้ามา

4. `base.py` แปลงเป็น Django settings

# config/settings/base.py
SECRET_KEY = settings.jwt_secret.get_secret_value()
DATABASES = {"default": {"ENGINE": "django.db.backends.postgresql", ...}}
PASSWORD_HASHERS = ["django.contrib.auth.hashers.Argon2PasswordHasher", ...]

Django ไม่รู้จัก Pydantic model โดยตรง; มันรู้จัก module ที่มีตัวแปรชื่อมาตรฐาน เช่น SECRET_KEY, DATABASES, INSTALLED_APPS. นี่คือเหตุผลที่มีทั้ง object ชื่อ settings และตัวแปร Django settings ตัวพิมพ์ใหญ่
