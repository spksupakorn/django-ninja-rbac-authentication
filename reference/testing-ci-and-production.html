Quick reference

Quality gates ของ Phase 1

Unit tests: password, JWT, AuthService และ edge cases
Integration tests: endpoint + auth guard + test database
Factory data: fixtures ที่อ่านง่ายและ reusable
CI: ruff + mypy + pytest ต้องผ่านก่อน merge
Production settings: DEBUG=False, hosts, secure cookies/headers

Definition of done: test ที่ตรงกับความเสี่ยงผ่านได้ซ้ำใน CI และ production config ไม่เปิด debug/security defaults ที่อ่อนเกินไป.
