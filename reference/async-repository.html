Async repository boundary

Service เรียก repository method
Repository ทำ async ORM query เช่น aget, acreate, afirst
await รอ database I/O โดยไม่ block event loop
Repository คืน model หรือ None ให้ service

กฎ: query ORM ที่ execute ใน async path ต้องใช้ async variant และอยู่ใน repository.
