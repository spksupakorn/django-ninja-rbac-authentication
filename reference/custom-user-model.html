Custom User ก่อน migration แรก

เลือก identity: email แทน username
สร้าง accounts.User และ UserManager
ตั้ง AUTH_USER_MODEL = "accounts.User"
สร้าง initial migration ของ accounts
migrate แล้ว model อื่นอ้างอิง user model นี้
กฎ: ตั้ง AUTH_USER_MODEL ก่อนสร้าง migration ใด ๆ ที่เกี่ยวกับ user. การสลับ user model หลังมี migrations/data แล้วเป็นงาน migration ที่ซับซ้อน
