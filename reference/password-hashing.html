Quick reference

Password hashing flow

Register: raw password → hash_password / set_password → Argon2id hash ใน DB
Login: raw password + stored hash → verify_password / check_password → True/False
Async service: ห่อ CPU-bound hash/verify ด้วย sync_to_async(..., thread_sensitive=False)

กฎ: ไม่เก็บ raw password, ไม่ decrypt hash, และทำ dummy verify เมื่อไม่พบ user เพื่อลด timing leak.
