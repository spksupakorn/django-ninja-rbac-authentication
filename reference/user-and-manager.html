Quick reference

User และ UserManager

Input: email + raw password
UserManager.create_user() normalize และ validate email
user.set_password() hash password; ไม่เก็บ raw password
user.save() บันทึก user

Model contract

  • email ต้อง unique
  • USERNAME_FIELD = "email"
  • REQUIRED_FIELDS = [] เมื่อ createsuperuser ไม่ต้องถาม field อื่น
  • is_active และ is_staff เป็น flags ที่ model กำหนดเอง
  • PermissionsMixin ให้ is_superuser, groups และ permissions
