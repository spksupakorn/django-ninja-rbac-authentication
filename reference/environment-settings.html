Settings และ environment

DJANGO_SETTINGS_MODULE เลือก config.settings.dev
dev.py import ค่ากลางจาก base.py
Settings(BaseSettings) อ่าน environment และ .env
validate ค่า เช่น PostgreSQL URL และ JWT secret
ส่งออก Django settings เช่น DATABASES, SECRET_KEY, DEBUG

จำง่าย

  • `.env` = ค่าเฉพาะเครื่องหรือ environment
  • `Settings` = schema ที่ตรวจค่าจาก `.env`
  • `base.py` = แปลงค่าที่ตรวจแล้วเป็น Django settings กลาง
  • `dev.py` / `prod.py` = ปรับ behavior ตาม environment
