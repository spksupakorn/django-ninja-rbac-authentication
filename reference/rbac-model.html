Quick reference

RBAC data model

User ← UserRole → Role
Role ← RolePermission → Permission
Permission code = resource.action, เช่น users.read

คำถามตรวจสิทธิ์: user นี้มี role ใดบ้าง และแต่ละ role มี permission code ใดบ้าง?

ข้อบังคับ: unique constraints ป้องกัน role หรือ permission ซ้ำในตารางเชื่อม
