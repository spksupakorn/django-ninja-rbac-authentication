Quick reference

JWT guard และ permission guard

HTTP Authorization: Bearer access-token
JWTAuth verify signature และ expiration
สร้าง principal: user_id, roles, perms → request.auth
require_permission(code) ตรวจ code in request.auth.perms

401: ไม่มี/invalid/expired token. 403: token valid แต่ไม่มี permission.
