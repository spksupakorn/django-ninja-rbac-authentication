Quick reference

Access + refresh token lifecycle

Login → access token (15m) + raw refresh token (7d)
DB เก็บ hash ของ refresh token พร้อม family และ revoked state
Refresh ปกติ → revoke token เก่า + ออก token ใหม่ใน family เดิม
ใช้ refresh token ที่ revoked ซ้ำ → revoke ทั้ง family → login ใหม่

กฎ: raw refresh token ส่งให้ client ครั้งเดียว; database เก็บ hash เท่านั้น.
