Quick reference

API → Service → Repository → Model

API: HTTP, schemas, validation, response
Service: business rules และ orchestration
Repository: async ORM queries เท่านั้น
Model: database schema และ persistence

กฎ: router ไม่ query ORM โดยตรง; service ไม่รู้จัก HTTP; repository เป็นจุดเดียวที่เขียน ORM query.
