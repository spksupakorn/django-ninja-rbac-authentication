# Mission: Understand the Django Ninja RBAC project

## Why
Use this repository to become able to read its code confidently: trace a request from the
server to an endpoint, understand why each file exists, and follow future RBAC/JWT work
without treating Django as magic.

## Success looks like
- Explain how a request to `/api/health` reaches the response in this project.
- Navigate settings, URL routing, Django apps, and tests before changing code.
- Read each M0–M8 implementation step and identify where its code belongs.

## Constraints
- Comfortable with Python, but new to Django.
- Learn from the codebase in short Thai lessons with a small hands-on exercise each time.

## Out of scope
- A comprehensive Django curriculum unrelated to this project.
- Building later RBAC/JWT milestones before their architectural foundations are understood.
